# Rolex Mobile — игровой мод (старая версия)

Исходный код игрового мода **Rolex Mobile** (ветка LIT / STAGE MOBILE) для SA-MP / CR-MP / open.mp на Pawn.
Мод разрабатывался под собственный Android-клиент и лаунчер, с кастомными RakNet/RPC-пакетами и мобильными интерфейсами.

> Это **старая версия** мода. Выкладывается как есть, без поддержки.

## Структура

```
gamemodes/
  new.pwn            — главный файл мода
  modules/
    core/            — переменные и стартовые конфиги под сборки (samp / crmp / matreshka / stage)
    dialogs/         — диалоги
    objects/         — объекты и карты
    textdraws/       — текстдравы
    other/           — игровые системы: инвентарь, транспорт, казино, работы, телефон,
                       планшет, семьи, тюрьма, квесты, теги игроков и прочее
  sql/               — SQL-дампы и структура базы
pawno/
  pawncc.exe         — компилятор Pawn
  include/           — инклуды (streamer, sscanf, Pawn.RakNet, Pawn.CMD, mysql, FCNPC, TOTP, sampvoice и др.)
plugins/             — плагины для SA-MP сервера (Linux .so)
plugins omp/         — плагины для open.mp сервера
config.json          — конфиг сервера open.mp
```

## Особенности ветки

- Связка игрового мода с собственным Android-клиентом и лаунчером
- Собственные RakNet/RPC-пакеты для интерфейсов, транспорта, тегов и игровых систем
- Лаунчерные аккаунты, выбор серверов, несколько персонажей на одном аккаунте
- Переработанные мобильные интерфейсы: инвентарь, донат, семьи, транспорт, выбор персонажа, админ-логи
- Персональные теги игроков и синхронизация названия семьи над персонажем
- Расширенная система личного транспорта: /cars, ПТС, кастомный handling, сохранение тюнинга
- Поддержка нескольких вариантов сборки: SA-MP, CR-MP, Matreshka, Stage

## Сборка

1. Выбрать нужный вариант сборки в `gamemodes/new.pwn` (дефайны под samp / crmp / matreshka / stage).
2. Скомпилировать:
   ```
   pawno\pawncc.exe gamemodes\new.pwn -igamemodes -ipawno\include -d3 -;+ -(+ -Z+
   ```
3. Залить SQL из `gamemodes/sql/` в MySQL и прописать доступы в конфиге.
4. Положить плагины из `plugins/` (SA-MP) или `plugins omp/` (open.mp) рядом с сервером.

## Важно

Мод будет адекватно работать **только на соответствующем клиенте** (Rolex / Lit / Stage Mobile).
На любом другом клиенте придётся переписывать значительную часть пакетов и интерфейсов.
